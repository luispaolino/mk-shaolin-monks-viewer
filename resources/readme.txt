Shaolin Monks Recomp - native Windows port by static recompilation (Direct3D 12)

The game is not included. Run ShaolinMonksRecomp.exe and select your own copy of
the original USA/Europe Xbox release of Mortal Kombat: Shaolin Monks. Setup accepts
ISO or XISO images (including .xiso.iso), ZIP files, or a complete extracted game
folder containing default.xbe.

ISO and XISO images are read directly. Keep the selected image or game folder
available. ZIP contents are imported once into:
%LOCALAPPDATA%\Shaolin Monks Recomp\game

Requires Windows 10 version 1903 or later, an x64 CPU with SSE4.2 and POPCNT,
and a GPU with Direct3D 12 support.

Saves: Windows Saved Games folder, under Shaolin Monks\hdd.
Settings, logs, caches, and crash reports: %LOCALAPPDATA%\Shaolin Monks Recomp
If an error occurs, the message identifies the session log. Closing the message
opens the application data folder.

F9 toggles FPS and frame time. F10 releases or captures the mouse pointer.
